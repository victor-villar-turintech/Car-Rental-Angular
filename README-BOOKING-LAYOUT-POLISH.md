# Booking layout polish

This patch improves the vehicle booking page without changing the underlying booking/payment flow.

Included changes:

- Keeps the vehicle image and vehicle details visible in a sticky left-side summary on desktop.
- Makes the booking/options column internally scrollable so long optional-services lists do not bury the car context.
- Adds a booking progress indicator.
- Reworks vehicle details into formatted spec cards, included-service chips and pickup summary.
- Groups optional services by category and makes each category collapsible.
- Adds a sticky booking total summary with availability and CTA.
- Adds a floating back-to-top button on the rental and confirmation pages.
- Improves responsive behaviour with a mobile-friendly stacked layout and sticky total summary.
